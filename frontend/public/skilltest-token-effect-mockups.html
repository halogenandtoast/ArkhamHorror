Skill test — token effect rows

One design, six palettes. Each row is segmented: a fixed 58px token cell on the left, divided by a hairline from the rules text on the right. Both cells centre on their own axis, so a one-line effect and a three-line effect both sit level with their token. Text is Noto Sans 13px/1.5 instead of the window's Times 16 — the toggles let you compare against Arno Pro and against what ships today. Every theme sets the same six variables (--band-bg, --row-bg, --cell-bg, --divider, --text, --val) and nothing else, so whichever you pick is a six-line change.
