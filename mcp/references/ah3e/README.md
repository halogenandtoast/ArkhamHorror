# Arkham Horror Third Edition references

Text extracted with pdftotext from the PDFs in ~/Code/Workspace (layout is lossy; the
Rules Reference is reflowed one numbered rule per line in rules-reference.txt).

Priority: FAQ (faq-2020-09-18.txt) > expansion rules > rules-reference.txt > learn-to-play.txt.

Card text is never read off the Workspace images — ask the user for it. What they have
transcribed for cards not yet implemented is kept under `card-text/`, verbatim; for cards
that are implemented, the code is the record. The expansion rules reproduce a handful of
cards in full, so check them before asking again.
