Homebrew framework landed 2026-07-13: fan campaigns Dark Matter (`z-dark-matter`, designer Axolotl) and Circus Ex Mortis (`z-circus-ex-mortis`, designer Tyler Gotch). Conventions in `docs/homebrew.md`: card codes `z-<slug>-NNN`, images at `img/arkham/homebrew/` (sibling of `cards/`), image manifests in `docs/homebrew/*.tsv`. ARCHITECTURE (reworked same day): everything for a campaign lives under `Arkham/Homebrew/<Name>/` with UNSUFFIXED names (Scenarios/, per-type impl dirs, CardDefs/, Sets.hs pattern synonyms over the open `Homebrew Text` EncounterSet constructor, Defs.hs + Content.hs exports); core tables take a single `(homebrew <>) $` merge from `Arkham.Homebrew.Defs` (CardDefs) and `Arkham.Homebrew.Registry` (impls/scenarios/campaigns, via HomebrewCampaign/HomebrewScenario existentials in Arkham.Homebrew.Types). Standalones = same directory shape minus Campaign.hs. Adding content = new dir ONLY: cards-discover (--only/--instances modes) generates instance-only imports into {Defs,Content,Token}Entries aggregators; central Defs/Registry/Tokens fold every IsHomebrewDefs/IsHomebrewContent/IsHomebrewTokens instance via TH reify (Arkham.Homebrew.TH.discoverInstances). Discovery is silently-empty on failure — HomebrewRegistrySpec pins totals. Slug/id convention (user's): leading colon, ':circus-ex-mortis' campaign id, ':circus-ex-mortis:223' card codes, ':circus-ex-mortis:moon' tokens; frontend routes homebrew/<campaign>/cards/<code>.avif. Frontend campaign assets at frontend/homebrew/<campaign>/ (KEBAB-case dir = campaign id sans colon, camelCases to i18n scope; @homebrew Vite alias): locales/en/*.json auto-merged (src/locales/homebrew.ts), *.css auto-injected + icons.json {key}/[key] icon hooks (src/arkham/homebrewAssets.ts), campaign.json (new-game entry incl. designer) + scenarios.json (scenario list w/ i18n keys, consumed by src/arkham/homebrewData.ts for campaigns list, scenario list, and generic campaign/scenario→i18n-scope mapping in types/Scenario.ts), img/ subtree = campaign images synced 1:1 to S3 img/arkham/homebrew/<campaign>/ by scripts/sync-homebrew-images.sh (make sync-images) and served at the same URLs in dev by the homebrewImages vite middleware (works with empty VITE_ASSET_HOST). Moon ICON art = img/icons/moon.png (user-fixed, do not touch); token FACE image = img/chaos-tokens/moon.png. Custom chaos tokens: open `CustomToken Text` ChaosTokenFace constructor (slug `z-<campaign>:<name>`); per-campaign `Tokens.hs` (pattern + CustomTokenDef with reveal semantic enum) registered in `Arkham.Homebrew.Tokens`; display/icon derive from slug by convention (`{moon}`/"Moon"; official token images at img/arkham/chaos-tokens/ct_*.png, custom at img/arkham/homebrew/<campaign>/chaos-tokens/<key>.png); JSON string-compatible with fallback parse (legacy "MoonToken" remapped) — same hazard/pattern as EncounterSet: adding a FIELD constructor to an all-nullary aeson-derived sum silently switches every constructor to tagged-object encoding and breaks saves; hand-write string instances with fallback.

**Done:** all 553 CardDefs + encounter sets + traits registered; both campaign layers (log keys, interludes, branching, epilogues, i18n); moon token ChaosTokenFace (frost-token pattern, seal-on-investigator, end-of-round release choice); DM Scan action + scanning deck + Memories (`IncrementRecordCountForInvestigator`); `nextSetupModifier`/`EffectNextSetupWindow` engine primitive (also fixed real TTITD bug: next-scenario penalties applied to current scenario — spec at tests/.../TheThingInTheDepthsSpec.hs); frontend Homebrew section with designer credits + z-code image routing.

**Pending:** all 16 scenario internals + ~500 card ability implementations (scenario runners are compile-clean stubs). Implementation data preserved in-repo at `docs/homebrew/data/`: full campaign-guide transcriptions, per-encounter-set inventories with OCR'd card BACKS (fan.json lacks back text), `codegen-report.json` zcode→identifier map, PROMPT-scenario-preamble.md for resuming agent fan-out. Wave-1 scenario agents died on monthly spend limit 2026-07-13.

**Why:** fan.json (arkham.build export) has no act/agenda back text and duplicate-row quirks (`is_duplicate_row`); CEM reuses official TheBayou/CurseOfTheRougarou sets (2 fan reprints skipped: z-circus-ex-mortis-020, -030).

**How to apply:** to resume scenario work, copy scratchpad homebrew/ data forward, follow PROMPT-scenario-preamble.md per scenario; DM helpers in `Arkham/Campaigns/DarkMatter/Helpers.hs` (scan/Memories API), CEM in `Arkham/Campaigns/CircusExMortis/Helpers.hs` (moon tokens, version swaps).
