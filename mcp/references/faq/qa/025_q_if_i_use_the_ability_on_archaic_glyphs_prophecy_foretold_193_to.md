# Q: If I use the ability on Archaic Glyphs (Prophecy Foretold) ( 193) to

Q: If I use the ability on Archaic Glyphs (Prophecy Foretold) ( 193) to
“automatically evade an engaged enemy,” does that mean an enemy engaged with
me, or an enemy engaged with any investigator?
A: By default, an “engaged enemy” is an enemy currently engaged with you. If
a card allows you to interact with any enemy engaged with an investigator, it
will specify that.
