# Q: If I commit Daring ( 111) to a skill test as Silas Marsh (        5) and use his

Q: If I commit Daring ( 111) to a skill test as Silas Marsh (        5) and use his
  ability to return it to my hand, do its effects still resolve?
  A: The lasting effect that grants the enemy retaliate and alert would
  continue for the duration of the skill test, since it is a lasting effect, and
  lasting effects persist for the specified duration regardless of whether the
  card that created the lasting effect is or remains in play. The second aspect
  of the ability, however, functions like any other ability on a skill card; it
  may only be used during the resolution of the skill test to which Daring is
  committed. (It is not a delayed effect.)
