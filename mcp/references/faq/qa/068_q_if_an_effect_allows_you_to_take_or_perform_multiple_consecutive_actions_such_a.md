# Q: If an effect allows you to take or perform multiple consecutive actions, such as

Q: If an effect allows you to take or perform multiple consecutive actions, such as
     with Eon Chart ( 100) or Nimble ( 17), are there player windows between
     these actions where I’d be able to play a fast card or resolve a free triggered ability?
     A: No, there are no player windows between multiple consecutive actions.
