# Q: If I use One-Two Punch ( 17) on an enemy with the elusive keyword,

Q: If I use One-Two Punch ( 17) on an enemy with the elusive keyword,
and that enemy leaves my location after the first attack, does the rest of the
attack resolve?
A: Yes. If an investigator uses an ability that allows them to perform
sequential attacks against a ready enemy with the elusive keyword, they
resolve each of those attacks against that enemy in succession, even if that
enemy changes location while the ability resolves.
