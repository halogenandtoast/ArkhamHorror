# Q: Can George Barnaby’s (       17) hand size be modified further beyond what

Q: Can George Barnaby’s (       17) hand size be modified further beyond what
     his ability states?
     A: Yes. While George Barnaby’s ability sets his base maximum hand size
     to be equal to the number of facedown cards beneath him (rather than the
     default value of 8), this value can then be modified by other abilities. (e.g.
     Arcane Enlightenment, Pelt Shipment, etc.)
