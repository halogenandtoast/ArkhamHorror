# Q: If I exile the last copy of an upgraded customizable card from my deck, would

Q: If I exile the last copy of an upgraded customizable card from my deck, would
  it retain those upgrades if I repurchase the card?
  A: No. If all copies of a customizable card are removed from your deck, any
  upgrades on the upgrade sheet are also removed. If those cards are later re-
  purchased, treat them as newly purchased cards with blank upgrade sheets.
