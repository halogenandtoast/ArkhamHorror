# Q: Does an enemy exhaust when an effect causes it to attack “as if it were the

Q: Does an enemy exhaust when an effect causes it to attack “as if it were the
  enemy phase?” What about an effect that causes an enemy to attack without that
  text?
  A: Yes, if an enemy attacks “as if it were the enemy phase,” it will exhaust
  after attacking. However, if an effect causes an enemy to attack without that
  phrasing, the enemy does not exhaust after attacking.
