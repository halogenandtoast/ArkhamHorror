# Q: If I use Katarina Sojka’s ( 69) ability while revealing tokens with Eyes

Q: If I use Katarina Sojka’s ( 69) ability while revealing tokens with Eyes
  of the Dreamer ( 67), does Katarina’s ability to “ignore” unresolved tokens
  combo with Eyes checking “ignored” tokens for a match?
  A: Yes. A token ignored via Katarina Sojka’s ability counts as “an ignored
  token” for Eyes of the Dreamer’s ability.
