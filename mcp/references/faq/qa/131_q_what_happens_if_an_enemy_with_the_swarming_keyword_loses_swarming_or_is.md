# Q: What happens if an enemy with the swarming keyword loses swarming or is

Q: What happens if an enemy with the swarming keyword loses swarming or is
     blanked, such as via Mind Wipe ( 68)?
     A: Swarming only resolves when the enemy with the swarming keyword
     enters play. If it later loses the swarming keyword or its text box is blanked, its
     swarm cards remain in play and it is still considered a host enemy.
