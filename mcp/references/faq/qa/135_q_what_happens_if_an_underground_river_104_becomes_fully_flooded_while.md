# Q: What happens if an Underground River (       104) becomes fully flooded while

Q: What happens if an Underground River (       104) becomes fully flooded while
  it is unrevealed, and then becomes revealed?
  A: It cannot be fully flooded once it has been revealed, so set it to the nearest
  state (in this case, partially flooded). Its forced effect fails.
