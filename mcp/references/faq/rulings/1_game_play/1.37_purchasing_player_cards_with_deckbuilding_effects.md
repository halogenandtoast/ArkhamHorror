# (1.37) Purchasing Player Cards with Deckbuilding Effects

When purchasing cards between scenarios, each card is purchased one
  at a time. If a card is purchased that has abilities that affect deckbuilding,
  upgrading, or purchasing cards, those abilities immediately come into effect
  for the current purchasing period.
  For example: Purchasing Adaptable ( 110) allows an investigator to swap
  level 0 cards immediately. Purchasing Underworld Market ( 77) immediately
  increases an investigator’s Deck Size.
