# (1.39) Revealing and Flipping Locations

If a location is revealed, then leaves play, and later re-enters play and is
  revealed again, place clues on it up to its clue value (as if this were the first
  time an investigator had revealed that location this game).
  If a location with 2 revealed sides flips without leaving play, do not place or
  replenish clues on that location when it flips unless otherwise stated.
