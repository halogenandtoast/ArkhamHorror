# (2.19) “Take an action” vs “Perform/resolve an action”

Some effects allow an investigator to “take” an action, usually of a certain
     type—for example, the ability on Ursula Downs ( 2) or Haste ( 239).
     If an effect allows an investigator to take an action, they effectively gain an
     action and then immediately spend it in order to take the action in question,
     meaning it follows all of the rules taking an action might normally follow: it
     may provoke attacks of opportunity, it counts as an action for the purposes
     of cards that count how many actions you have taken, etc.
     Some other effects, such as Quickdraw Holster ( 89), allow an
     investigator to “perform” or “resolve” an action. Such effects typically
     specify that they ignore that action’s  cost. In this case, no action has
     been gained or spent, and the action is resolved as specified.
