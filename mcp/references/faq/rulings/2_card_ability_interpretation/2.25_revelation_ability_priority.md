# (2.25) Revelation Ability Priority

If an investigator has both a Dilemma card and a weakness and/or
  encounter card in their hand, the weakness and/or encounter card must be
  resolved first. If a Dilemma card is drawn while resolving a skill test, resolve
  the skill test in full before resolving the Dilemma’s Revelation effect.
