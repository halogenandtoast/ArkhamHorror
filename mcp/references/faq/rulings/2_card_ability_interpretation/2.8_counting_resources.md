# (2.8) Counting Resources

If an ability refers to the number of “resources you have,” “your resources,”
  or any variation on the above, it is only referring to the number of resources
  in that investigator’s resource pool. Resources on other cards that
  investigator controls do not count toward this total unless explicitly stated.
