# Rulings and Clarifications

This section contains additions and clarifications to the core game rules.
  Each entry is presented with a unique section number so it can be easily
  identified when making rulings, answering questions, or otherwise referring
  to the entry.
  It should be used in conjunction with the Rules Reference to establish the
  rules of play. If the text of this document directly contradicts the text of the
  Rules Reference, the text of this document takes precedence.
