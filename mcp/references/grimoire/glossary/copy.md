# Copy

A copy of a card is defined by title. A second copy of a card is any other card
  that shares the same title, regardless of cardtype, text, artwork, or any other
  differing characteristics between the cards.
  When a card exits and re-enters play, it is considered to be a new copy of
  itself. As a result, any aspect of the game state that applied to it previously
  no longer applies.
