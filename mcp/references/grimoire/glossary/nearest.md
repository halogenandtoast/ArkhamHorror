# Nearest

Some card abilities reference the “nearest” entity. Nearest refers to the
  entity of the specified kind at a location from which the shortest distance
  (by movement) to the subject of the ability is the lowest out of all eligible
  entities. In the event of a tie, the lead investigator decides which location or
  entity is the “nearest.”
  • The path to the nearest entity is the “shortest” path to that entity.
