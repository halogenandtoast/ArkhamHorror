# VII. Card Anatomy

This section presents a detailed anatomy of each cardtype. Pages
 32–33 detail scenario cards, and pages 34–35 detail investigator
 and player cards.
 Scenario cards include act cards, agenda cards, location cards, treachery
 cards, enemy cards, and scenario reference cards.
 Player cards include investigator cards, investigator mini cards, asset cards,
 event cards, and skill cards.
