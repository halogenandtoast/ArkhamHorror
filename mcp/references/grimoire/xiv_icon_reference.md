# XIV. Icon Reference

The following is a list of set icons used to identify each previously released
  Arkham Horror: The Card Game product. A list of icons for products
  released prior to 2026 can be found in the legacy FAQ document on the
  Fantasy Flight Games website:

  This section lists each campaign along with their associated icon so players
  can tell, at a glance, what campaign a particular card is from.
      AHC100 Core Set (Brethren of Ash)
