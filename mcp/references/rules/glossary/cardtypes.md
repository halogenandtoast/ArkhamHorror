# Cardtypes

The game's cardtypes are presented in Appendix IV, with detailed card
anatomies (see "[Appendix IV: Card Anatomy](#Appendix_IV_Card_Anatomy)"
on page 28).

- If an ability causes a card to change its cardtype, it loses all other
  cardtypes it might possess and functions as would any card of the new
  cardtype.

See also: "[Asset Cards](#Asset_Cards)" on page 4, "[Enemy
Cards](#Enemy_Cards)" on page 10, "[Event Cards](#Event_Cards)" on page
11, "[Location Cards](#Location_Cards)" on page 14, "[Skill
Cards](#Skill_Cards)" on page 18, "[Treachery Cards](#Treachery_Cards)"
on page 20.
