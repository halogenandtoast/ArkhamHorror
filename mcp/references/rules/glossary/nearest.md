# Nearest

Some card abilities reference the "nearest" entity. Nearest refers to
the entity of the specified kind at a location that can be reached in
the fewest number of connections, even if one or more of those
connections are blocked by another card ability. The path to the nearest
entity is the "shortest" path to that entity.
