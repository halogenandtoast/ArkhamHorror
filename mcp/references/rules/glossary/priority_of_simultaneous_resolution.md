# Priority of Simultaneous Resolution

If an effect affects multiple players simultaneously, but the players
must individually make choices to resolve the effect, these choices are
made in player order. Once all necessary choices have been made, the
effect resolves simultaneously upon all affected entities.

- If two or more forced abilities (including delayed effects) would
  resolve at the same time, the lead investigator determines the order
  in which the abilities resolve.
- If two or more constant abilities and/or lasting effects cannot be
  applied simultaneously, the lead investigator determines the order in
  which they are applied.
