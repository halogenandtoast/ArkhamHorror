# Ready

A card that is in an upright state so that its controller can read its
text from left to right is considered ready.

- The default state in which cards enter play is ready.
- When an exhausted card readies, it is returned to the upright state.
  It is then said to be in a ready state.
- A ready card cannot ready again (it must first be exhausted, typically
  by a game step or card ability).
