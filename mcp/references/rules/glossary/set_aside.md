# Set Aside

Some scenarios instruct the players to set aside specific cards.
Set-aside cards have no interaction with the game until they are
referenced by instructions within the scenario or by a card ability.

<span style="color:blue">(Added in FAQ, section 'Card Ability
Interpretation', point 2.7)</span> If an effect instructs an
investigator to take control of a card that is currently set-aside, that
effect puts that card into play in that investigator’s play area.
