# The letter "X"

The value of the letter X is defined by a card ability or a granted
player choice. If X is not defined, its value is equal to 0.

- For costs involving the letter X, the value of X is defined by card
  ability or player choice, after which the amount paid may be modified
  by effects without altering the value of X.
