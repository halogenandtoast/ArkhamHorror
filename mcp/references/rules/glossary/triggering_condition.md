# Triggering Condition

A triggering condition indicates the timing point at which an ability
may be triggered. Most triggering conditions use the word "when" or
"after" to establish their relation to the specified timing point.

- Each eligible ability that triggers in reference to a specified timing
  point may be used once each time that timing point occurs.
- If multiple instances of the same ability are eligible to initiate,
  each instance may be used once.
