# Wild Skill Icons

A Wild (\[wild\]) skill icon on a player card may be used to match any
other skill icon for the purposes of both card abilities and counting
how many matching icons are committed to a skill test. When using Wild
icons for the purpose of resolving a card ability, a player must state
which icon the Wild is matching at the time the card is used.

Wild icons committed to a skill test are considered "matching" icons for
the purposes of card abilities.
